# 换一圈 前端 UI 全面改版 · 任务提示词

把本提示词连同 images 文件夹里的参考图一起交给执行改版的编码工具。

## 一、项目背景

- 产品：换一圈，重庆移通学院的校园以物换物 + 二手交易平台，移动端网页，单页应用，hash 路由。
- 现有技术形态：原生 HTML/CSS/JS（app.css + app.js），后端 Spring Boot，所有数据走现有接口。
- 本次任务性质：只做前端 UI 与交互改版。**不许改动任何后端接口，不许删除或阉割任何现有功能**，新界面必须把现有功能全部承接住。
- 现有功能清单（改版后一个都不能少）：注册登录（邮箱验证）、商品发布与上下架、交换单、出价、拍卖、心愿单、站内私聊、通知、双向评价、举报、信用分、社区、语义搜索、图片上传、管理后台。

## 二、总体设计原则

1. 参考图是闲鱼的界面截图，**只借布局结构和信息层级，不许照抄**：配色、图标、文案、细节处理都要换成换一圈自己的，成品第一眼要像一个校园产品，不像闲鱼换皮。
2. 全站配色用下面这套设计变量，**禁止再出现整站灰度**。注意：现有 app.css 里变量名叫草绿、橙、红，但变量值全是灰色，那是历史遗留的错误，本次必须按下面数值恢复为真实彩色，并全站统一引用变量，不许在页面里散写颜色值。
   - 主色（深青绿，取自吉祥物发色）：`--green-700:#0A5C51; --green-600:#0C7263; --green-500:#0F9B84; --green-400:#3CBFA8; --green-100:#DCF2EC; --green-50:#EDF7F4;`
   - 品牌亮青（小面积点缀、品牌标识）：`#00BAAE`
   - 强调橙（拍卖、成环提醒、热度标签）：`--orange-700:#C56F0D; --orange-500:#F08C1A; --orange-50:#FDF1DE;`
   - 警示红（只给信用分数字、未读角标、删除类操作）：`--red-500:#E5484D; --red-50:#FDEEEE;`
   - 中性：`--ink-900:#21302B; --ink-700:#43564F; --ink-500:#71857D; --bg:#F5F8F6; --surface:#FFFFFF; --line:#E4ECE8;`
   - 深色品牌色（做深色品牌带和深色锚点用）：`--green-900:#06302A; --green-800:#084239;`
   - 点缀金（只许极小面积使用：logo 描点、深色带上的细分隔线、信用极好徽章的描边）：`--gold:#C9A24B;`
3. 圆角统一：小卡片 12px、常规卡片 16px、大区块 22px、胶囊 999px。阴影统一带一点绿调，禁止纯黑硬阴影。
4. 字号下限：正文不小于 13px，辅助文字不小于 11px，10px 只允许用在角标上。现有界面小字过多的问题必须改掉。
5. 页面最大宽度 430px 居中，两侧留白背景用浅灰绿。所有可点元素点击热区不小于 40px。
6. 图标按下面图标系统一节执行，全站统一。**界面元素里禁止出现 emoji**：导航、服务入口、按钮、标签、筹码、空状态、商品占位图都不许用 emoji 充当图标或图样；emoji 只允许出现在用户自己发布的内容里。
7. **背景层级（高级感的来源，硬性要求）**：页面不许从头到尾铺满浅青色。每屏的背景必须有三层：页面底色（`--bg` 或白色）、至少一处**深色锚点**（深青绿 `--green-800` 到 `--green-900` 的横幅、卡片或区块，白字）、白色内容卡。深浅对比拉开之后，浅色才显贵；只有浅色没有深色，成品会显得廉价和平淡，这一条验收时重点查。点缀金只在深色锚点和 logo 上小面积出现，不铺大面。
8. **筹码与页签规范**：一切横向筹码（频道行、筛选筹码、分类小页签）都必须有**完整的椭圆胶囊填充底**，不许只有文字或只有细描边。未选中：`#E7EFEA` 实底加墨色字；选中：`--green-600` 实底加白字加粗；高度 30px，左右内边距 13px，筹码里带图标时图标在文字左侧、同色。这一条包括首页频道行。

### 图标系统（硬性规范，全站统一）

- 风格定死一种：**线性图标**，24px 画布，描边 1.8px，圆角端点和圆角转折，不填充（选中态可填充为实心版，但造型必须与线性版同一套轮廓）。全站交付为一套 SVG，一次定义处处引用，不许每个页面各画一套、不许混用其他图标库的现成图凑数。
- 造型要有校园二手这件事的创意，不许用通用模板糊弄。下面这批是必须专门设计的服务与功能图标，造型要点写死：
  - 校内上门：一扇宿舍门加定位针，门微微开着
  - 以物换物：两个弧形箭头绕成一圈，圆心放一个小纸箱，这是全站的招牌图标，导航和标签上反复出现
  - 好物估价：放大镜，镜片里是一个小价签
  - 教材专区：一本立着的书，书脊上有书签垂下来
  - 毕业季专场：学位帽，帽穗垂在一侧
  - 失物招领：一把钥匙，钥匙环上挂一个小定位针
  - 语义智搜：放大镜加一颗四角星火花
  - 拍卖：小槌子落在底座上
  - 心愿单：星星落在开口纸箱里
  - 面交约定：两个定位针之间一条虚线路径
  - 发起交换：左右两件小商品之间一个双向箭头
- 其余通用图标（搜索、相机、消息、我的、社区、设置、返回、关闭、收藏、分享、定位、筛选、箭头类）也按同一描边规格自己画齐，清单在动手前先列全，缺一个补一个，不许临时拿 emoji 或系统字符顶替。
- 服务入口的图标底：浅绿圆底（`--green-50` 填充，图标用 `--green-700` 描边），六个入口的圆底大小、图标视觉重量必须一致。

## 三、吉祥物 IP：猫猫

见 `images/13-吉祥物-猫猫原图.jpg`（深底探头版）和 `images/14-吉祥物-极简logo透明底.png`（极简版）。她是换一圈的官方吉祥物，定位相当于闲鱼的小黄鱼，按下面规则穿插全站：

**形象可以变，识别点不许变。** 她的动作、姿势、展示方式（探头、半身、全身）、画风精度（完整版、极简版、纯线条描边版）都可以按页面场景自由调整，怎么适配页面怎么来；但以下核心识别点在任何变体里都不许改：深青绿发色与发髻加金色发饰、齐刘海、贴脸下垂的辫子与粉青珠子、金耳坠、两个大小相同的纯黑纵向胶囊眼睛、没有嘴巴和鼻子、浅粉腮红。需要新动作时，以包内图片为基准图按同一扁平色块风格生成，比例和配色与基准保持一致。

**透明底是硬性规则**：13、15 到 18 是带深炭色方形底（底色 `#27292D`）的原图，只许用在底色与之相同或接近的深色区块上，方形边缘要与区块底色融为一体、看不出边界。界面其他任何地方（浅色背景、白色卡片、浅色横幅）一律用 21 到 25 的透明底版本直接贴合背景，**浅色底上出现黑色方块视为不合格，必须返工**。新生成任何变体时，交付物必须是透明底 PNG。
- 顶部栏与品牌区：用极简 logo 版，配站名换一圈。
- 空状态（无搜索结果、空消息、空收藏、空订单、还没有发布）：用探头版，从容器边缘探头，配一句小管家口吻的文案。
- 安全提醒：面交安全提示、交易须知、私聊页的系统提醒由她以小管家身份发言，头像用极简 logo 版。
- 状态反馈：发布成功、交换达成、成交成功页用她做主视觉；加载中用她的头像做呼吸动画；404 和网络错误页用探头版。
- 客服与官方通知：头像统一用极简 logo 版。
- 约束：一屏最多出现一次，禁止满屏堆砌；包内已有的资源优先直接引用，缺动作时按上一条的规则生成新变体；核心识别点的配色不许改，图片不许拉伸变形。

## 四、底部导航栏

参考 `images/01-首页.jpg` 和 `images/02-消息列表.jpg` 底部的导航样式。

- 五栏固定为：**首页、社区、发布、消息、我的**。其中原导航里的交易入口取消，改为消息；发布做成中央凸起的圆形按钮，主色填充，比两侧高出一截。

## 五、首页

参考 `images/01-首页.jpg`。

- 顶部：第一行是频道页签：首页、集市、社区、拍卖，当前页签加粗带下划线，右上角放一个小的签到或活动入口位（可留空位，不放广告）。
- 搜索框：整行圆角胶囊，左侧带扫码样式的装饰图标，占位词轮播校园热词（如高数教材、宿舍小冰箱），右侧相机图标（拍照搜货，先做 UI，点击可先提示开发中），最右是深色搜索按钮。
- 频道横滑行：关注、推荐、新发、心愿单、语义智搜、教材、数码、运动，可以横向滑动。每个频道都是带填充底的椭圆胶囊（按第二节筹码规范），语义智搜的胶囊里带智搜小图标。
- 服务入口行（**本页与参考图差异最大的地方，务必校园化**）：参考图里是吃喝玩乐、手机数码、上门回收、二手车、领红包、特惠充值，全部换成校园服务，定为这一组：**校内上门、以物换物、好物估价、教材专区、毕业季专场、失物招领**。每个入口按图标系统一节的造型，用统一线性 SVG 图标加浅绿圆底，下方配文字，可横滑，带分页小点。不许用 emoji 或彩色立体图标。
- 欢迎横幅（本页的深色锚点，紧跟服务入口行）：一整条深青绿渐变横幅（`--green-900` 到 `--green-700` 斜向渐变），左侧白字标题闲置别吃灰，换一圈看看，副文案写本校同学正在交换的件数（走现有数据，没有就写固定文案），下面一个白色实底的去发闲置按钮；右侧用挥手透明底版（图 25）半身探出横幅下沿。下沿可压一条 1px 的金色细线作点缀。这条横幅是全页配色的压舱石，不许改成浅色。
- 成交动态：横幅下放一条白色细条，左侧橙色浅底小标签写成交动态，右边滚动最近的成交与交换达成（走现有接口）。
- 商品流：双列瀑布流卡片。卡片结构自上而下：商品图、标题（最多两行）、一行橙色小字热度标签（如本月销量领先、运动族都在看，文案按分类生成）、价格行（价格用深青绿粗体，想要人数在右侧灰色小字）、卖家行（头像、昵称截断、信用徽章如卖家信用极好用橙色浅底标签）。以物换物的商品要在图片左上角加深青绿底的以物换物标签，并显示想换什么；拍卖商品加橙色拍卖中标签和剩余时间。
- 已成交的商品保留在流里时，图片上盖半透明的已换出印章（参考个人主页里的卖掉了水印样式，做成换一圈自己的印章，不要照抄闲鱼字样）。

## 六、消息列表页

参考 `images/02-消息列表.jpg`。

- 顶栏：左侧大标题消息，右侧三个图标依次为搜索（查找消息）、消息管理（批量已读和清理）、设置（消息设置），点击分别进入搜索会话、消息管理模式、消息设置页。

- 私聊会话直接排在系统消息下方，中间用时间分组标题隔开（参考图里的 1 个月以前的消息这种分法）。
- 会话行结构：圆形头像、第一行昵称加交易状态徽章（交易成功用绿色浅底小标签）、第二行最后一条消息摘要（一行截断）、下方小字时间、右侧商品缩略图圆角小图、未读用红点或数字角标。官方小助手会话（如卖家小助手）带服务号小标签，头像用吉祥物。

## 七、私聊页

参考 `images/03-私聊-展开功能面板.jpg` 和 `images/04-私聊-收起状态.jpg`。

- 顶栏：返回箭头、对方昵称（加粗）加信用徽章（如卖家信用极好，金色浅底胶囊）、昵称下方小字是脱敏会员名，右上角更多按钮。
- 商品卡固定在顶栏下方：左侧方形商品图、中间价格（红色大字）和一行小字（同校面交免邮费这类信息按交易方式显示）、下方灰色交易状态（交易成功、待确认、交换中），右侧主操作按钮（胶囊，去评价、确认收货、发起交换，按订单状态切换）加一个展开箭头，展开后显示订单详情。
- 系统提示条：全宽橙红色警示条的样式保留，用于如由于对方设置，你无法与 ta 进行对话这类系统级提示；普通安全提醒用吉祥物小管家条（浅绿底加吉祥物头像）。
- 系统卡片：确认收货卡、评价引导卡（快给 ta 一个评价吧加去评价按钮）按参考图的灰底大圆角卡片样式，文案适配换物场景。
- 消息气泡：对方在左，白底；自己在右，主色深青绿底白字。已发送消息下方带已读小字。时间分隔用居中灰色小胶囊。
- 特殊消息卡：交换达成卡（橙色渐变大卡，写明双方换出的物品和已达成交换，点击查看交换单），替代参考图里的转账卡；面交约定卡（地点加时间，点击打开地图或复制地点）。
- 底部输入栏：语音按钮、圆角输入框（占位文案想跟 TA 说点什么）、表情按钮、加号按钮，固定在底部。
- 加号展开面板：点击加号在输入栏下方展开九宫格面板，动画要平滑。格子按本平台实际功能定为：**相册、拍摄、发送位置、发送宝贝、约面交、发起交换**。参考图里的语音通话、视频通话、转账不做（网页端没有这些能力，不要放假按钮）。

## 九、设置页

- 帮我处理分组，一张卡：好物估价（拿放大镜的吉祥物图 17，填几项信息先给个参考价区间，接我的页的估价入口，是同一个功能）。

- 底部居中一个关闭叉号，点任意卡进入对应编辑页（拍卖和心愿的编辑页在闲置编辑页基础上改字段，不另做一套版式）。

编辑页（发闲置）：

  - 分类：必选，点开分类面板（教材书籍、数码、宿舍好物、运动、服饰、生活等）
  - 价格：点开价格面板，填售价和原价，带一个可小刀开关

  - 面交地点：参考图的所在位置改成校内地点选择，选项是书院和常用面交点（图书馆门口、缤果大街等），可保存常用地点
  - 送达方式：仅面交、校内可送，两项开关
