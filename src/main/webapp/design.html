换一圈 · 校园以物换物平台
界面设计稿与设计规范

移动端优先，基准画板 375 × 812。视觉方向参考清新电商风：浅薄荷底、草绿主色、红色强调数字、大圆角卡片。下文尺寸均为 1x 逻辑像素，导出 @2x 即 750 × 1624。

画板 375 × 812 栅格 4px 内容边距 16px 主色 #2E9E4B 正文字号 15 / 24 字体 PingFang SC
怎么读这份稿子：第 02–05 节是可量取的原子规格（颜色、字阶、间距、组件），第 06 节是九张 1:1 页面效果图， 图上红色编号对应每张图下方的说明。前端代码 app.css 里的 CSS 变量与本文数值一一对应，改一处两边同步。

01设计原则

三条，从产品定位推出来的，后面所有取舍都服从它们。

原则 做法 为什么
东西比人多 列表以物品为主体，人退到标题下一行，只留昵称和信用分 用户来这儿是找东西，不是找人。人物信息多了反而挡住物品
下一步只有一步 每个页面底部只放一个主按钮，次操作用幽灵按钮或收进弹层 换物最大的流失点是"不知道接下来干嘛"。一屏一个主行动
闭环要看得见 三方环用环形图 + 一句话白话流程，不用箭头流程图 "你把键盘给雨桐，雨桐把耳机给阿哲…"这句话比图更好懂

07核心流程与页面跳转

两条主路径。一对一走报价，三个人走环。两条最后都汇进交换单。

路径 A · 一对一

集市→ 物品详情→ 选择我的物品（弹层）→ 报价列表→ 对方接受→ 交换单 · 待交付→ 双方确认收货→ 互评

路径 B · 三方环

我的 · 我的物品→ 点"找环"→ 三方环结果→ 成环（锁三件物品）→ 三人各自确认→ 约面交→ 三人各自点已交换→ 信用分 +2
两处必须给足反馈，否则用户会以为没点成功：
① 成环瞬间，三件物品变"锁定"，列表里整卡降透明度，并弹一次 toast「环成了」；
② 最后一次确认收货的瞬间，页面立刻切到"已完成"，并提示可以打分。这两处是全程情绪最高点。

08响应式规则

先做手机，桌面只是"把一列拆成两列"，不做另一套设计。

断点 布局变化 说明
< 640px 单列，底部导航 主战场。卡片左图右文，列表纵向滚
≥ 640px 统计四列，弹层居中 弹层从底部升起改为中心浮层，圆角四角对齐
≥ 760px 物品两列 内容最大宽 1080，左右留白自动居中
≥ 900px 隐藏底部导航，顶部改横向导航 桌面用鼠标，底部导航够不着；动作栏取消吸底
≥ 1080px 物品三列 再宽也保持三列，卡片不拉伸超过 360

09交付说明（Figma 对照）

这份 HTML 是可直接量取的等效设计稿。要在 Figma 里 1:1 复刻，按下面命名建库即可，数值不用再调。

Figma 对象 命名 内容
Frame 01_登录 / 375×812 九张页面各建一个 Frame，命名用「序号_页面名」
Color Styles brand/700, ink/900, line, bg … 第 02 节全部色值，命名与 CSS 变量一致
Text Styles display/h1/h2/h3/body/small/caption/mini 第 03 节八级，行高按表填，字重 400/500/600
Effect Styles shadow/sh-1, sh-2, sh-3 第 04 节三个阴影，直接抄数值
Components btn/primary, chip/on, card/item … 第 05 节八个组件，按钮做 default / hover / disabled 三态
落地代码：src/main/webapp/assets/styles/desktop/app.css 里的 :root 变量就是第 02–04 节的机器可读版本， 页面样式全部引用变量。改配色只需改 :root 一行，本节表格同步改一行即可。
