# 换一圈 UI 改版验收记录

本轮为本地前端改版。首页及搜索使用线上只读商品数据复核，登录后页面用 Playwright 拦截现有接口并提供测试数据。提交发布、真实私聊收发、拍卖出价和交易成交未在正式站点执行。

## 技术检查

- JavaScript 语法、Maven 离线编译、前端差异检查通过。
- 430px 对八页及表单、附件展开、顶部弹窗、评价和搜索结果状态进行截图。首页另外检查 1280px，两种宽度都使用真实商品列表。截图场景无 JS 异常和横向溢出。真实搜索「高数」接口返回 HTTP 200，展示 7 张结果卡。
- Impeccable critique 结合独立视觉审查和浏览器检测，修正辅助文字对比度、选中态、商品图高度、私聊物品缩略区、搜索返回对齐及点击热区。Polish 复核了截图和功能状态。公共路由检测未见主要告警，底栏按规格保留短促回弹。
- 按 Web Interface Guidelines 检查键盘焦点、按钮语义、表单名称、图片尺寸与异步提示。加上跳至主要内容、主内容焦点目标和提示播报，扩大主要控件点击区域。存量样式及全部登录后分支未逐项通过完整无障碍验收。[Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)
