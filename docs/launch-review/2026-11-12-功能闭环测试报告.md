# 换一圈功能闭环测试报告

测试日期 2026-11-12，时区 Asia/Shanghai

## 结论

注册、发布审核、搜索、报价、一对一与三方交换、私聊、评价、拍卖、心愿、社区、举报和新增运营后台的主要流程已在真实后端跑通。手机收藏和关注依赖的接口失败，部分设置只在本机保存。当前不能判定全部功能闭环通过。测试未修改线上数据库，运营后台新版未部署。

## 环境和证据

- 当前工作区 Java 源码经 Maven 离线编译。使用独立 MySQL 数据目录和本地临时 Java 实例，加载项目 SQL 与迁移。使用三个普通测试账号和一个测试管理员。
- Chromium 桌面视口为 1280×800，手机视口为 430×932。真实交易用浏览器和 HTTP 请求组合完成。部分 UI 检查使用 Playwright 模拟数据。

## 已发现缺口与处理顺序

| 优先级 | 问题与实测证据 | 影响 |
| --- | --- | --- |
| P1 | 手机 `GET /api/social/favorite/check`、`GET /api/social/follow` 返回 HTTP 500 且响应非 JSON。当前 Java 路由未注册 `/api/social/*` | 手机收藏状态和关注列表无法形成真实服务闭环。桌面本机收藏和历史与这组接口是不同实现 |
| P1 | `GET /api/user/settings` 返回业务码 400，手机设置会回退到本地存储 | 本机可保存部分偏好，无法确认跨设备同步。自动回复目前是草稿 |
| P2 | `GET /api/item/deals` 返回业务码 400 | 手机首页成交动态缺少可用数据源 |
| P2 | `GET /api/notification/summary` 返回业务码 404 | 旧统计地址不可用。现行手机消息页已从通知列表计算未读，本次红点闭环通过 |

## 尚未覆盖

- 手机真机相机、HEIC、软键盘、权限拒绝与弱网。超限图片通过浏览器文件选择器模拟注入。
- 邮箱实际发信、验证码过期和重试，以及语义模型的排序质量。只验证了邮箱状态接口和关键词回退。
- 心愿自动匹配提醒、拍卖自然到期任务、审核自动通过定时任务、社区图片和物品分享、Scrap Arena 实际对局。
- 二级设置逐项保存、账号安全与资料编辑完整流程、封禁后已有会话的撤销、管理后台的所有异常输入、线上并发和容量。
